# NailsApp

**Agenda, clienti e conti di una nail artist, in tasca.**

NailsApp è una webapp per una nail artist: agenda degli appuntamenti, schede clienti, listino, guadagni e spese, con il riepilogo mese per mese.

Questo repository è la **demo statica** della webapp: grafica e funzioni sono quelle dell'app vera, che salva i dati in un database MySQL tramite PHP. È una versione dimostrativa: non c'è un backend e clienti, appuntamenti e conti sono di fantasia. Il PIN per entrare è 1234.

👉 **Demo:** [margheritafolegatti.github.io/NailsApp](https://margheritafolegatti.github.io/NailsApp/)

## Linguaggi

HTML, CSS e JavaScript, senza framework.
